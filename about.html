Engineering first

My background is in engineering rather than page layout: production software that has to keep running unattended, hardware-control systems that talk to physical instruments, and data tooling where a wrong answer is worse than no answer.

I also build my own products. I built and run Bibooks, a bilingual audiobook site for learning languages, which turns any text into a bilingual audiobook; I also run its blue/green deploys and monitored nightly backups. The Square Word Calligraphy lab is a free in-browser tool with a layout engine and renderer I wrote. Nuestra Finca is a 3D walkthrough of a hillside farm, rebuilt from phone photos. Every project gets the same discipline.

How I work

Three principles

  • Built to hold up

    I assume something will eventually go wrong: a traffic spike, a failed update, an outage. Nobody can promise software never has a bad day. My job is to make the bad day survivable and fixable.

  • Radical clarity

    Every decision, mockup and status update comes in plain language you can act on. If I can't explain it simply, I haven't thought it through.

  • Long-term thinking

    I choose tools that age well and keep you free of lock-in, so each change is easier than the last. Shortcuts today become debt tomorrow.

The name
